# COMP 6700 Project 

## Introduction 

In this research project, you will need to use generative AI tools for deriving defects and threat models for Visual Studi Code (VSCode) extensions. 


## Task-1

- Task1.1: Write multiple prompts for three geenrative AI tools ChatGPT, Gemini, and Claude. These prompts will identify the defect categories for VSCode extensions.   
- Task1.2: Write multiple prompts for three geenrative AI tools ChatGPT, Gemini, and Claude. These prompts will identify the consequences of the defect categories for VSCode extensions. 
- Task1.3: Write multiple prompts for three geenrative AI tools ChatGPT, Gemini, and Claude. These prompts will need to identify a mapping between the identified defect categories and defect consequnces.   

### Deliverables
- `defect-categories.txt`: this will contain all the defect categories that you identified 
- `defect-consequences.txt`: this will contain all the defect consequences that you identified 
- `defect-mapping.txt`: this will contain a table that maps each defect category and defect consequence that you have identified 
- `defect-prompt.txt`:  this will contain all the prompts you used for Task1-Task3. 


## Task-2

- Task2.1: Write multiple prompts for three geenrative AI tools ChatGPT, Gemini, and Claude. These prompt will identify the threats, risk level of threats, and threat actors.  
- Task2.2: Use the three generative AI tools to obtain a profile on the potential attackers in the developed threat models obtained from Task1. 


### Deliverables
- `threat-prompt.txt`: this will contain all the prompts you used 
- `threats.txt`: this will contain all the threats you identified  with their threat levels 
- `threat_models.txt`: this will contain all the threat models you identified 
- `threat-actors.txt`: this will contain all the actors you identified from the threat models     


## Rubric 

- Task-1: 50% 
- Task-2: 50%

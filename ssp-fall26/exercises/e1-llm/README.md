## Dynamically Execute LLM-generated Code

### Background

Can we use LLM-generated code right away? We will answer this question by doing this simple exercise.

### Steps

- 1. Use ChatGPT ot Google Gemini to execute the following prompt:

```
Generate a python code that can perform classification using the fine tuned BERT langauge model 
```

- 2. Copy and paste the generate code in `llm.py`

- 3. Execute the the generated code without making any modifications to llm.py 

- 4. Report the errors in `error.txt`

- 5. Reprompt the generative AI tool to fix the errors. Record the suggestions and apply the suggestions until all errors are resolved. Save all your prompts in `reprompt.txt` and all suggestions generated by the generative AI tool in `suggestions.txt` 

### Rubric

- llm.py: 20%
- error.txt: 20%
- reprompt.txt: 30%
- suggestions.txt: 30%
